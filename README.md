## 💡 Sobre mim

Desenvolvedor Fullstack Java com base sólida em algoritmos, complexidade computacional e teoria dos grafos, construída durante 2 anos como bolsista PIBIC na UFPA. Essa formação me ensinou a **pensar antes de codificar**: analisar eficiência, decompor problemas complexos e buscar soluções elegantes.

Atualmente trabalho na área de TI/Telecom (Vellon Telecom), atuando com monitoramento de redes (Grafana), diagnóstico de falhas e suporte técnico — o que me trouxe uma visão combinada de **infraestrutura, usuário final e desenvolvimento de software**.

- 🔭 Atualmente aprofundando em **arquitetura de microsserviços em Java**, orquestração com **Docker Compose** e pipelines de **CI/CD via GitHub Actions**
- 🌱 Aprofundamento em serviços como **Docker, Kubernetes e CI/CD** para deploy de aplicações em nuvem
- 🤝 Aberto a oportunidades como **Desenvolvedor Fullstack Java Júnior**
